# TradeDesk Local

TradeDesk Local 是一款轻量、本地优先的外贸业务与单证桌面工具，同时面向 Windows 和 macOS。当前版本为单用户模式，业务数据默认存储在 SQLCipher 加密数据库中，不依赖本地 Web 服务或云端账号。

## 当前能力

- 产品、客户和供应商主数据：新建、编辑、搜索、停用及历史引用保护；客户档案包含三类地址、购买意向、客户分析、优劣势和主要联系人；供应商档案包含地址、联系人、银行、币种、付款条件、资质评估，以及按产品维护的采购价、MOQ 和交期。
- 自选配置产品：组件库预录品名、型号/规格/材质、默认数量、单位、单价、品牌和备注；选择组件后生成可调数量与单价的组合报价清单，并冻结历史价格快照。
- 多语组件词库：类别、品名、品牌、规格、单位、备注、配置产品名称和配置说明自动记忆，可提前维护六种目标语言译文、停用词条并模糊搜索复用。
- 配置报价换算：组件价格默认以 CNY 维护，外币配置手工录入当日人民币牌价后自动换算并冻结汇率、日期和本次报价单价；币种统一从常用币种下拉选择。
- 配置单输出：保存后的自选配置可导出英语、俄语、法语、西班牙语、葡萄牙语或阿拉伯语 A4 横向 PDF/CSV，并输出汇率快照、从最终 PDF 打印；中文业务词缺少目标语译文时禁止混合语言导出。
- 企业单证标识：在“企业设置”维护公司名称、Logo、电子签名和电子章，资料保存在 SQLCipher 加密工作区，统一应用到配置单和全部业务单证 PDF 的页眉、签名区与页脚。
- 业务单：同一产品选择器支持标准产品和已保存的自选配置产品，冻结客户、产品、配置价格、币种、贸易术语、付款和交期快照；业务单中心可直接切换状态并记录审计事件。
- 成本估算：按业务单维护材料、加工、包装、国内外物流、税费、佣金、保险、认证等完整成本，可带入同币采购明细并自动计算目标毛利报价。
- 利润与风险工作台：可选择任意业务单，按采购单保存的汇率快照折算实际采购成本，集中查看收款、采购/生产/发运覆盖率，并识别缺少成本估算、报价低于目标、缺失汇率、延期、负毛利和跨单证阻断风险。
- 采购与生产：同一业务单按供应商拆单并自动生成业务单派生采购编号；采购单可修正成本、数量、供应商、币种、汇率和交期，跟踪六阶段生产进度，并按所选公司及签章生成 PDF、CSV 和打印版。
- 装运与收款：维护货代等履约合作方，按业务单产品行建立多个装运批次并保护累计发货数量；跟踪预付款、尾款、分期款、实收和逾期风险。
- 销售单证：商业报价单、形式发票、外贸合同。
- 履约单证：商业发票、详细装箱单、运输唛头、发货人委托书、提单补料、保险申请、报关资料、原产地证明申请、检验证书申请、熏蒸证书申请和受益人证明。
- 报价可转换为 PI/合同，PI 可转换为合同/商业发票，商业发票、箱单、委托书、报关资料和提单可继续生成认证及信用证资料；全程复用已签发快照。
- 保险金额按货值与加成自动计算，预计保费按费率联动；受益人证明检查信用证有效期与交单截止日；正式提单、保单、证书、信用证正本和银行回执作为对应记录的加密附件归档。
- 单证草稿、单用户审核、签发冻结、作废、归档、新版本和历史搜索；履约与认证资料自动交叉校验数量、金额、件数、重量、CBM、HS 编码、原产国、港口、船名航次、装运日期与唛头。
- Typst 专业 A4 模板，长字段可单行自适应缩放，支持 PDF、CSV 和从最终 PDF 打印。
- PDF 导出记录路径、SHA-256、时间和对应的加密业务快照。
- 数据保护：首次升级生成离线恢复密钥；支持加密备份、恢复验证与撤销恢复，备份默认保存到“文档/TradeDesk Backups”。
- 加密附件库：业务单、成本估算、采购单、生产节点和单证页面可直接上传查看，系统自动关联当前记录；文件保存到 SQLCipher 并记录大小与 SHA-256。
- 全日期编号：新业务单、采购单、配置单、装运批次、收款计划和单证统一使用“前缀-YYYYMMDD-四位流水号”。
- 单证自动草稿：编辑停止 900 ms 后写入加密数据库，异常退出后再次打开同一单证可恢复；正式保存或签发后自动清理。

项目继续采用原生 React、CSS 与精简 Rust/SQL，未引入 UI 组件框架、Redux、ORM 或后台服务。

## 前端开发

需要 Node.js 20+ 和 pnpm：

```powershell
pnpm install
pnpm dev
```

构建验证：

```powershell
pnpm build
```

## 桌面开发环境

共同依赖：

- Rust stable（rustup）
- Node.js 20+
- pnpm
- Tauri CLI（项目开发依赖）
- Typst 0.15.1

Windows 还需要 Microsoft C++ Build Tools、WebView2 Runtime、Strawberry Perl 和 NASM。可在管理员 PowerShell 中执行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\setup-windows-dev.ps1
.\scripts\verify-dev.ps1
pnpm tauri dev
```

macOS 还需要 Xcode Command Line Tools：

```bash
bash scripts/setup-macos-dev.sh
pnpm tauri dev
```

生产构建：

```powershell
pnpm release:windows
```

该命令会校验并准备 Typst 0.15.1 运行时，再生成包含 PDF 引擎的当前用户级 NSIS 安装包。安装包位于 `src-tauri/target/release/bundle/nsis/`。macOS 在原生 Mac 上执行：

```bash
bash scripts/setup-macos-dev.sh
pnpm tauri build --bundles app,dmg --ci --no-sign
```

无签名构建仅用于内部测试。对外发布前，Windows 必须使用正式代码签名证书签名；macOS 必须使用 Developer ID Application 证书签名并完成 Apple 公证。

## 单证使用路径

1. 创建或首次升级加密工作区后，将一次性显示的恢复密钥保存到密码管理器或离线打印；再在“企业设置”录入公司、Logo、电子签名和电子章。
2. 建立产品、组件、客户和供应商；需要组合报价时先保存自选配置产品，并在词库中补齐目标语言译文。
3. 新建业务单；从分组产品选择器中选择标准产品或币种一致的已完成自选配置，报价业务可从“报价”阶段开始。
4. 在“成本估算”按业务单建立完整成本，可带入同币采购明细并补充包装、物流、税费、佣金等项目；异币采购在采购单保存汇率快照后由工作台自动折算。
5. 在“单证中心”创建商业报价单，处理阻断校验后提交审核，再签发冻结。
6. 对已签发报价选择“转换单证”，生成 PI 或合同草稿；商业发票签发后可继续生成箱单、唛头、委托书、提单、保险、报关、原产地、检验、熏蒸和受益人证明资料。
7. 继续采购和六阶段生产；附件直接添加到对应业务单、成本估算、采购单、生产节点或单证。
8. 在“装运与收款”建立合作方、分批装运和收款计划，再生成完整履约资料；正式提单、正式保单等机构文件上传到对应单证附件，签发前处理跨单证校验差异。
9. PDF/CSV 默认保存到用户“文档/TradeDesk Exports”。
10. 在“数据与安全”创建 `.tdbackup` 加密备份；需要恢复时先锁定工作区，再在解锁页选择备份文件。

“打印”会先生成与预览一致的最终 PDF，再使用系统默认 PDF 阅读器打开。

## 数据与版本

- 当前应用版本：0.26.0；数据库为 SQLCipher Schema V15。客户与供应商完整档案、供应商产品采购条件、自选配置、采购汇率快照、多语组件词库、业务单产品来源、成本估算、合作方、装运批次、收款计划、附件和自动草稿通过增量迁移兼容旧数据，销售单证字段保存在向后兼容的 JSON 快照中。
- 0.26 发布门禁会用真实 SQLCipher 旧库样本验证 V4/V7/V12/V14 升级，生成并逐页渲染 21 份单证/配置单/采购单 PDF，同时用 10,000 个产品、3,000 个客户和 1,000 个供应商建立性能基线。该门禁只用于开发与发布，不增加安装后运行依赖。
- 恢复密钥库与业务数据库分离并同样使用 SQLCipher 加密；恢复密钥只在生成时显示，软件无法再次读取原密钥，只能轮换生成新密钥。
- 加密备份包含数据库和恢复密钥库，不包含明文密码；恢复后的原工作区安全副本只有在新数据成功解锁后才会清理。
- 旧单证在读取时自动补齐报价有效期和折扣默认值，无需手动迁移。
- 已签发版本只读；修改必须创建新版本。
- 当前 V1.0 仍为单用户。V1.1 再增加同机多人账号、角色权限和审核流。
