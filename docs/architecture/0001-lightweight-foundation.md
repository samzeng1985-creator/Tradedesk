# ADR-0001：轻量单体桌面架构

状态：已接受（初始实现）

## 决策

V1.0 使用单一 Tauri 桌面应用：React/TypeScript 负责界面，Rust 负责领域、加密存储、文档和平台能力。没有独立服务器、微服务、前端全局状态框架或通用 ORM。

## 约束

- UI 不直接执行 SQL。
- SQLCipher 数据库是唯一结构化事实源。
- 已签发单证保存不可变业务快照。
- PDF 通过 Typst 模板生成，打印使用生成后的 PDF。
- V1.1 同机多账号继续使用同一进程和数据库；局域网多人另立架构决策。

## 为什么轻量

- 单仓库、单安装包、单数据库。
- 仅 React、Tauri 和必要的 Rust 库。
- 不引入 Redux、GraphQL、消息队列、容器或后台服务。
- 模块边界通过 Rust module 和小接口维护，需求证明必要前不拆 crate。
