## 用户简单验收清单

请只用一笔脱敏的真实订单完成以下 6 项，每项回答“通过”或附截图：

- [ ] Windows：从产品/自选配置建立业务单，拆成两个供应商采购单，修改采购价并确认工作台人民币成本与美元利润正确。
- [ ] Windows：依次更新六阶段生产进度、异常、装运和收款；关闭并重开软件，数据仍正确。

- Apple Silicon 实机安装、安全提示、打印机和文件权限。
- Windows 安装、覆盖升级和卸载测试；当前 Windows 用户存在真实工作区，自动脚本为保护数据会主动停止。
