## RC1 范围

## 放行规则

- 任一 P0 缺陷、数据库损坏、备份无法恢复、金额错误或已签发单证可被静默修改，RC1 不得放行。
- P1 缺陷必须修复或形成有负责人、期限和规避方法的书面记录。
- 自动门禁和实机验收均完成后，才允许建立 `v0.27.0-rc.1` 标签并保存双平台安装包、SHA-256、QA 报告及验收记录。
