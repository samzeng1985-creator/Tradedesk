# TradeDesk 0.24.0 发布工程说明

## 本阶段目标

0.24.0 只处理 1.0 发布阻断项，不增加新的业务模块。目标是让同一代码提交能够在 Windows 和 macOS 原生环境中生成结构一致、包含 PDF 运行时、带校验和的无签名发布候选。

## Windows 发布候选

```powershell
pnpm install --frozen-lockfile
pnpm test
cargo test --manifest-path .\src-tauri\Cargo.toml
pnpm release:windows
```

输出目录：`src-tauri/target/release/bundle/nsis/`。

安装方式为当前用户安装，不要求管理员权限。安装包包含 TradeDesk、Typst 0.15.1、Typst 许可证与声明；WebView2 缺失时由安装程序静默补齐。

生成发布清单：

```powershell
.\scripts\write-release-manifest.ps1 `
  -ArtifactPath .\src-tauri\target\release\bundle\nsis\TradeDesk*.exe `
  -Platform windows-x64
```

## macOS 发布候选

必须在原生 macOS 环境运行：

```bash
pnpm install --frozen-lockfile
pnpm test
bash scripts/setup-macos-dev.sh
cargo test --manifest-path src-tauri/Cargo.toml
pnpm tauri build --bundles app,dmg --ci --no-sign
```

输出目录：`src-tauri/target/release/bundle/macos/` 和 `src-tauri/target/release/bundle/dmg/`。

## 当前发布门禁

- 无签名产物只能用于内部测试，不能作为正式 1.0 安装包发布。
- Windows 正式发布需要可用于桌面应用的代码签名证书或可信签名服务。
- macOS 正式发布需要 Apple Developer 账号、Developer ID Application 证书和公证凭据。
- 必须在隔离测试账户完成干净安装、0.23.x 覆盖升级、卸载后工作区保留、重新安装后数据可解锁四项验证。
- 必须在真实 Apple Silicon Mac 完成 PDF、打印、附件、备份恢复和 DMG 拖放安装烟雾测试；Intel/Universal 仍是 1.0 发布门禁。

## 自动化产物

`.github/workflows/release-candidates.yml` 在版本标签或手工触发时并行生成：

- `TradeDesk-Windows-x64-unsigned`
- `TradeDesk-macOS-arm64-unsigned`
- 各平台 `SHA256SUMS.txt`

签名和公证密钥不会进入普通 CI。后续取得证书后，应增加受保护的正式发布作业，并由环境审批后读取签名凭据。
