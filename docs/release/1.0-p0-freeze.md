# TradeDesk 1.0 P0 范围冻结

冻结日期：2026-08-11  
基线版本：0.23.0

## 1.0 必须交付

- 单用户、本地优先、SQLCipher 默认加密、恢复密钥、加密附件、备份与恢复。
- 产品、客户、供应商、自选配置及组件主数据；供应商与产品的采购价、MOQ 和交期关系。
- 业务单、成本估算、供应商拆单采购、六阶段生产、分批装运、分次收款与风险工作台。
- 基础销售、履约、运输、报关及证书资料；PDF、CSV 和打印。
- 草稿、审核、签发、作废、归档、版本快照、历史检索和跨单证校验。
- Windows 10/11 与 macOS 安装、升级、签名、公证、双平台回归及真实订单试点。

## 1.0 不再增加

- 同机多人账号、角色权限和多人审核流。
- 局域网多设备、云同步、第三方 ERP/CRM/海关接口。
- Word/Excel 单证输出及整套单证 ZIP；主数据 Excel 导入导出继续保留。

## 0.24.0 发布工程进展

- Windows NSIS 和 macOS `.app/.dmg` 无签名发布候选已配置为双平台 CI 构建。
- Typst PDF 运行时和许可声明已纳入平台安装包资源，安装后无需用户配置开发工具链。
- 每个平台发布候选自动生成 SHA-256；本地发布清单可记录版本、平台、大小、Schema 与签名状态。

## 当前剩余发布阻断项

- Windows NSIS 干净安装、覆盖升级、卸载保留工作区验证和正式代码签名。
- macOS 原生硬件上的 `.app/.dmg` 烟雾测试、Apple Silicon/Intel 验证、签名和公证。
- UI E2E、数据库逐版本升级、PDF 黄金样例、性能与大数据量测试矩阵。
- 中国出口及美国、欧盟、中东、东南亚、俄罗斯区域模板复核记录。
- 真实订单全流程试点和异机备份恢复演练。

冻结后，除 P0 缺陷、跨平台兼容、安全及验收问题外，不再向 1.0 增加新模块。
