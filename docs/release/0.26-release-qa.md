# TradeDesk 0.26.0 发布质量门禁

0.26.0 不增加业务模块，目标是把数据库兼容、单证版式和性能变成可重复的发布证据。应用继续使用 React、Rust、SQLCipher 和 Typst，以下 Python/Poppler 工具只用于开发和发布检查，不会随应用安装，也不是用户运行环境要求。

## 覆盖范围

- SQLCipher：V4、V7、V12、V14 加密样本升级到 Schema V15；检查核心数据、加密文件头、数据库完整性和外键。
- PDF：14 类外贸单证、英语/俄语/法语/西班牙语/葡萄牙语/阿拉伯语配置单和采购单，共 21 份。
- PDF 页面：文件集合、页数、纸张尺寸、可提取文字边界、空白页、Poppler PNG 渲染和人工总览。
- 性能：10,000 产品、3,000 客户、1,000 供应商；记录加密批量写入、列表读取、前端同等模糊筛选和数据库体积。

## 发布环境

- 项目原有 Node.js、pnpm、Rust、Tauri 和 Typst 0.15.1 工具链。
- Python 3.11+，开发包固定为 `pypdf 6.10.0`、`pdfplumber 0.11.9`、`Pillow 12.2.0`。
- Poppler，命令行中可访问 `pdftoppm`。

Windows 安装发布检查依赖：

```powershell
python -m pip install pypdf==6.10.0 pdfplumber==0.11.9 Pillow==12.2.0
choco install poppler -y
python scripts/run-release-qa.py
```

macOS 安装发布检查依赖：

```bash
python3 -m pip install pypdf==6.10.0 pdfplumber==0.11.9 Pillow==12.2.0
brew install poppler
python3 scripts/run-release-qa.py
```

每次运行使用 UTC 时间建立独立目录，默认输出到 `output/release-qa/0.26.0/`。目录内包含原始 PDF、逐页 PNG、总览图、性能 JSON 和总报告，不会把上一次残留文件误算为本次结果。
