# TradeDesk 0.25.0 安装与升级验收

## 安全前提

Windows 自动安装测试只允许在隔离测试账户运行。脚本会在以下任一情况出现时立即停止：

- TradeDesk 正在运行；
- Windows 注册表中已有 TradeDesk 安装记录；
- 开始菜单或桌面已有 TradeDesk 快捷方式；
- `%APPDATA%\cn.treedeep.tradedesk` 已存在。

因此它不会在真实工作区所在账户中自动执行安装、升级或卸载。

## 干净安装与卸载

```powershell
.\scripts\test-windows-installer.ps1 `
  -CurrentInstaller ".\src-tauri\target\release\bundle\nsis\TradeDesk Local_0.25.0_x64-setup.exe"
```

检查内容：

1. NSIS 静默安装成功；
2. 主程序、卸载器、Typst、许可证和声明均存在；
3. 应用数据目录测试哨兵在安装后存在；
4. 安装程序创建开始菜单或桌面快捷方式；
5. 静默卸载成功，主程序、快捷方式与卸载注册表记录被清理；
6. 应用数据目录测试哨兵在卸载后仍存在；
7. 脚本只清理自己创建的测试哨兵目录，并生成 JSON 报告。

## 0.24 → 0.25 覆盖升级

```powershell
.\scripts\test-windows-installer.ps1 `
  -PreviousInstaller ".\TradeDesk-0.24.0-Windows-x64\TradeDesk-0.24.0-Windows-x64-setup.exe" `
  -CurrentInstaller ".\src-tauri\target\release\bundle\nsis\TradeDesk Local_0.25.0_x64-setup.exe"
```

升级时使用同一隔离安装目录。报告应依次出现 `previous-install`、`upgrade` 和 `uninstall`，且 `workspacePreserved` 为 `true`。

## macOS 发布候选检查

```bash
bash scripts/setup-macos-dev.sh
pnpm tauri build --bundles app,dmg --ci
bash scripts/verify-macos-bundle.sh
```

内部测试构建使用 ad-hoc 签名，避免 Apple Silicon 将完全未签名的下载应用报告为损坏；正式发布仍需 Developer ID 签名和 Apple 公证。

该检查验证 `.app` 版本、Mach-O 主程序执行权限、内置 Typst 执行权限和许可文件，并调用 `hdiutil verify` 检查 DMG。它不能替代真实 Mac 上的窗口、PDF、打印、备份恢复、Gatekeeper、签名和公证验收。
