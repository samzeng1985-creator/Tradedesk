- 在采购条件录入 `1234567890.12`，确认采购单价不再受 9.99 限制。
- 新建业务单 `TD-20260818-2801`，在列表直接变更业务状态。
- 销售币种为 USD、采购币种为 CNY，按手工汇率 7.2 生成人民币 600,000.00 元采购成本。
- 工作台显示销售额 `US$100,000`、折算采购成本 `US$83,333`、采购覆盖率 `100%`。

- 在 8 个主要模块之间连续导航，并在主数据执行模糊搜索。
- 锁定并关闭应用，重新启动、解锁后核对产品、客户、供应商、业务单、采购金额、生产节点与工作台金额均已持久化。

## 复跑方式

在 Windows 开发环境中先构建独立 QA 标识的可执行文件，再运行交互驱动。输出目录必须是新的测试目录：

```powershell
pnpm tauri build --config src-tauri/tauri.qa.conf.json --no-bundle --ci
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/run-windows-ui-e2e.ps1 `
  -Executable src-tauri/target/release/trade-desk-local.exe `
  -DriverScript scripts/windows-ui-e2e.mjs `
  -OutputDirectory output/windows-ui-e2e/0.28.0-rc.2/manual-run
```

脚本只允许清理 `%APPDATA%\cn.treedeep.tradedesk.rc2qa` 和 `%LOCALAPPDATA%\cn.treedeep.tradedesk.rc2qa` 两个精确路径，并在开始与结束时清理 QA 数据。
